# 科学探索门户 · 说明

单文件页面：`science-explore/index.html`。不改 Pages 设置，也不动其他目录。

## 这扇门在模仿什么

三间实验室的颜色、字体和操作是分开借来的，门厅只负责把它们接在一起。

- **物理器械室**：白底 32px 网格、钢蓝 `#3266c5` / `#284c79`、微软雅黑字距。展架有台面和前缘，教具悬停上浮并弹出预览卡，点击拆开。入口文案沿用「悬停看运行 · 点击拆开探索」。
- **元素周期表**：暗底 `#171c20`，DM Sans，矿物色键帽（非金属、稀有气体、碱金属、过渡金属）。悬停 `translateY(-5px)`，按下沉回，滚入时有一次落键。
- **基因表达**：暖纸 `#fbfaf7`、金色播放钮、等宽眉题。右侧是 `#132427` 暗场和雾化边缘，碱基色 A `#c5b775`、T `#9caec6`、G `#90a998`、C `#c79e92`。点击、拖动或方向键查看配对。

## 开场编排

全屏画布，不是 SVG 加 `translateZ`。火箭、星野、喷流和揭幕都画在同一张画布上。

时间（正常运动，约 8.5 秒）：

1. **远 → 近（0–2.8s）**  
   距离从 26 收到 2.15，曲线 `easeOutCubic`：前半段较快，后半段明显减速。星点按径向拉成速度线，喷口粒子拖在后面。机身略有横向漂移，并在接近时收回到中线。高速时船体有一层很轻的重影。
2. **减速并锁定中心（2.8–5.2s）**  
   距离在 2.15 附近做一次轻微前倾再回到原位。四角对焦框淡入。高光从机头扫到机身。标题「开始探索新的教育可能」在减速末段淡入，停在画面下方。
3. **加速退回远方中心（5.2–7.2s）**  
   `easeInQuad`：先慢后快，距离回到 26，构图从偏上回到几何中心。标题与对焦框随距离褪去，速度线反向拉出，发动机缩成中心的一点光。
4. **波纹揭幕（7.2–8.5s）**  
   先停一拍，再从中心光点挖开一道带起伏的圆孔。三道涟漪（冷钢色和一圈淡金）跟着波前扩开。暗角和颗粒随孔洞一起散掉，下面是纸色门厅。

跳过开场会立刻进入约 0.7 秒的揭幕，不把页面硬切出来。揭幕结束前页面锁住滚动。导航在整个开场里不出现。

## 导航

顶栏文案是 **首页**、物理、化学、基因、关于。没有「开场」。

波纹完全结束后，再等第一次滚动（`scrollY > 24`）才把顶栏滑入。只滚动、不提前显示。

## 减弱动效

`prefers-reduced-motion: reduce` 时不跑飞行、不拉速度线、螺旋和键帽也不循环。画面停在居中的火箭和标题上，大约 0.7 秒后用淡出代替波纹。顶栏仍然要等揭幕结束并且用户滚动。

## 叠卡

物理、化学、基因三张卡片 `position: sticky`，高度约为 `(100dvh - 导航) × 0.67`。下一张紧接在文档流里，所以静止时底部大约露出三分之一。基因后面是一张较矮的收束幕布。`scroll-snap-type: proximity`，停靠时对齐卡片顶部。

## 本地预览

```bash
python3 -m http.server 8765
```

打开 http://127.0.0.1:8765/science-explore/

页面只依赖字体 CDN，逻辑都在这一个 HTML 里。
